Rover missions

Open index.html in a browser. The page needs the internet once, so it can load the 3D library.

The pictures sit in the art folder, saved as WebP. Keep that folder next to index.html.

To put this on another GitHub repo:
1. Open the other repo on github.com.
2. Click Add file, then Upload files.
3. Drag this whole rover_missions folder onto the page. Include index.html, how-to-upload.txt, and the art folder.
4. Commit the upload.

After that, open index.html from the repo to play.

Six true or false questions:

The score is how many Mars days the rover lasts, times how many kilometres it travels. True
A bigger battery lasts longer, and it also costs more and adds weight. True
In a dust storm, extra solar panels help a lot because the sun is still strong. False. The sky is brown and the sun is weak, so the battery does most of the work.
Set the kilometres in the storm to zero and the rover still travels, it just travels slowly. False. It waits, and it does not travel.
A night heater that is too small lets the cold reach the computer. False is wrong — this one is True. Nights fall to about −130°C.
If the instruments on the nuclear rover are switched off, almost none of the drive counts. True
